\begin{abstract}
函数级代码生成系统在部署时同时受到接口计费、上下文长度与调用预算约束，核心问题是如何把有限测试时计算投向最能提升通过率的环节。本文提出预算分档编排协议，在统一执行器、统一判定口径和统一令牌记账下，将流程组织为单步、单步+修补、分流重链与救援、级联四个可比较档位，用以刻画不同预算投向形成的成本--收益前沿。基于 HumanEval 164 题与 MBPP 清洗集 427 题的实验表明，以 \texttt{claude-sonnet-4-6} 为主模型时，MBPP 通过率由 $82.51\%$ 提升至 $91.72\%$，HumanEval 由 $97.56\%$ 提升至 $99.80\%$。机制实验进一步显示，结构难度分能够作为预算分配先验，固定轻/重路径多重集对照揭示结构对齐在 MBPP 上带来额外通过样本，压缩失败回注在五随机种子下保持相近通过率并降低平均令牌。累计收益率 $\rho$ 表明，单步+修补具有最高边际效率，级联档提供最高通过率上限。本文为函数级代码生成的测试时编排提供了一套可复现、可解释、可记账的实验口径。
\keywords{函数级代码生成；测试时计算；预算分档；失败修补；级联编排；成本收益前沿}

\begin{center}
    \textbf{Abstract}
\end{center}
Function-level code generation systems are constrained in deployment by API cost, context length, and call budgets. The key question is how to allocate limited test-time computation to stages that most improve correctness. This paper proposes a budget-tiered orchestration protocol that fixes one executor, one correctness criterion, and one token-accounting pipeline, then organizes generation into four comparable tiers: single-step generation, repair after failure, difficulty-aware rescue, and cascaded orchestration. Experiments on HumanEval-164 and MBPP-sanitized-427 with \texttt{claude-sonnet-4-6} show that the pass rate rises from $82.51\%$ to $91.72\%$ on MBPP and from $97.56\%$ to $99.80\%$ on HumanEval. Mechanistic results show that structural difficulty scores serve as useful budget priors, fixed light/heavy-path multiset controls expose the effect of structural alignment, and compressed failure feedback preserves comparable accuracy with lower average token use across five seeds. The cumulative gain-rate frontier $\rho$ indicates that single-step repair delivers the strongest marginal efficiency, while cascaded orchestration reaches the highest pass-rate ceiling. The protocol offers a reproducible, interpretable, and cost-accountable basis for studying test-time orchestration in code generation.

\textbf{Keywords:} function-level code generation; test-time computation; budget tiering; failure repair; cascade orchestration; cost--benefit frontier
\end{abstract}
